# 01 · 需求说明

## 一句话

按下全局快捷键，像 PixPin 截图一样框选屏幕上的一块区域，该区域内的文字被自动识别并翻译，译文以一个可拖动、可缩放的浮窗"滤镜"覆盖显示在原区域上；浮窗移动或改变大小后，自动对新覆盖的区域重新识别翻译。

## 核心交互流程

1. **触发**：全局快捷键（默认 `Alt+T`，可配置）在任意应用上按下。
2. **框选**：出现全屏半透明遮罩，光标变为十字；按住左键拖出一个矩形选区，松开即确认；`Esc` 取消。
3. **翻译**：确认选区后立即对选区截屏 → OCR 提取文字 → 调用翻译 API → 在选区位置弹出翻译浮窗显示译文。
4. **滤镜浮窗**：
   - 浮窗初始位置和大小与选区一致，置顶显示。
   - 可随时**拖动**（按住浮窗任意空白处）和**缩放**（拖拽边缘/角落）。
   - 位置或尺寸变化停止后（防抖约 300ms），自动对浮窗当前覆盖的屏幕区域重新截屏 → OCR → 翻译，刷新译文。重新截屏前浮窗需短暂隐藏，避免拍到自己。
   - 浮窗上有最小化的操作钮：关闭、复制译文、固定（暂停自动刷新）。
   - `Esc` 或关闭钮关闭浮窗。
5. **多实例**：允许同时存在多个翻译浮窗（再次按快捷键新开一个）。

## 功能需求

| 编号 | 需求 | 优先级 |
|---|---|---|
| F1 | 全局快捷键触发框选（快捷键可配置） | P0 |
| F2 | 全屏遮罩框选，支持多显示器 | P0（多显示器 P1） |
| F3 | 选区截屏 + OCR（Windows 原生 OCR，离线） | P0 |
| F4 | 翻译引擎可配置：默认免 key 引擎（Edge / Bing），可选 Google 免费、微软/DeepL/Google 官方 API、DeepLX、OpenAI 兼容大模型；可同时配置多个并设定主用与回退顺序；目标语言可配 | P0 |
| F5 | 译文浮窗：置顶、拖动、缩放、变化后自动重译 | P0 |
| F6 | 复制译文、固定（暂停刷新）、关闭 | P1 |
| F7 | 设置界面（快捷键、翻译引擎选择与参数、回退顺序、目标语言、源语言自动检测） | P1 |
| F8 | 多浮窗并存 | P1 |
| F9 | 视觉直译模式（VLM 直接看图翻译，跳过 OCR） | P2 · 预留扩展点 |

## 明确不做

- 图像编辑、标注、贴图等截图软件功能。
- 历史记录/生词本（以后再说）。
- macOS / Linux 支持（第一版只做 Windows）。

## 验收标准（第一版）

- 在浏览器、PDF 阅读器、任意桌面应用上，快捷键 → 框选英文段落 → 2 秒内浮窗显示中文译文。
- 拖动浮窗到另一段文字上，松手后自动刷新为新译文。
- 修改配置文件中的 base URL / key / 模型后重启生效（有设置界面则免重启）。
- OCR 失败、API 失败时浮窗内有可读的错误提示，不崩溃。
