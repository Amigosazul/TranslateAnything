# 01 · 需求说明

## 一句话

按下全局快捷键，像 PixPin 截图一样框选屏幕上的一块区域，该区域内的文字被自动识别并翻译，译文以一个可拖动、可缩放的浮窗"滤镜"覆盖显示在原区域上；浮窗移动或改变大小后，自动对新覆盖的区域重新识别翻译。

## 核心交互流程（2026-11-16 用户改定为沉浸式实时翻译）

1. **触发**：全局快捷键（默认 `Alt+T`，可配置）在任意应用上按下。
2. **框选**：屏幕**不置灰**，只画选区边框；按住左键拖出矩形，松开即确认；`Esc` 或右键取消。
3. **沉浸式覆盖**：确认后选区变成一个只有边框的"翻译框"。框内文字按段落识别，在**原文所在位置**用取样的背景色盖住原文、以取样的文字色显示译文，字号自动适配，看起来像软件本身就是这种语言；不另开窗口显示译文。
4. **实时翻译**：翻译框持续检测框内画面，内容一变就重新识别，不是一次性翻译。
5. **跟随滚动/缩放**：框内内容滚动或缩放时，译文随之平移/重排；已翻译过的段落直接复用缓存，只有新进入框内（上下左右）的文字才请求翻译。
6. **不打扰原软件**：翻译框默认鼠标穿透，滚轮、点击都作用于下方软件；鼠标移到框边缘可拖动缩放，移入框内时右上角出现工具条：移动、显示原文/译文、暂停/继续、关闭。
7. **多实例**：允许同时存在多个翻译框（再次按快捷键新开一个）。

## 功能需求

| 编号 | 需求 | 优先级 |
|---|---|---|
| F1 | 全局快捷键触发框选（快捷键可配置） | P0 |
| F2 | 全屏遮罩框选，支持多显示器 | P0（多显示器 P1） |
| F3 | 选区截屏 + OCR（Windows 原生 OCR，离线） | P0 |
| F4 | 翻译引擎可配置：默认免 key 引擎（Edge / Bing），可选 Google 免费、微软/DeepL/Google 官方 API、DeepLX、AI 翻译（OpenAI 兼容大模型）、离线翻译；普通引擎、AI 翻译、离线翻译在**同一个列表**里混排，从上往下调用、出错换下一个；列表项可删除，用弹窗选类别和服务后配置添加，同一种服务可加多份；目标语言可配 | P0 |
| F5 | 沉浸式翻译框：原位覆盖译文、实时刷新、跟随滚动/缩放、只翻新内容、鼠标穿透、可拖动缩放 | P0 |
| F6 | 工具条：显示原文/译文切换、暂停/继续、关闭；出错时显示原因 | P1 |
| F7 | 设置界面（快捷键、翻译引擎选择与参数、回退顺序、目标语言、源语言自动检测） | P1 |
| F8 | 多浮窗并存 | P1 |
| F9 | 视觉直译模式（VLM 直接看图翻译，跳过 OCR，译文在浮窗内集中显示），用于本机 OCR 读不出的画面；在悬浮窗设置里切换"识别方式" | P2 · 预留扩展点 |
| F10 | 翻译过滤：自动跳过无需翻译的文字（代码、路径、版本号、已是目标语言等），支持用户不翻译词表/正则/强制翻译（全局 + 按应用），每次跳过都能说明原因，误判可在管理界面一键纠正 | P1 |
| F11 | AI 翻译（大模型引擎，可选，非默认；界面统称"AI 翻译"）：结构化翻译并判断是否保留原文，结果写回译文库；悬浮窗可用"OCR 定位 + VLM 理解"（列表中单项开启视觉，一次完成纠错 + 翻译，本机 OCR 保留），沉浸模式用 LLM 带上下文批量翻译；可按应用关闭 | P2 |
| F12 | 语言包模式（"汉化"）：读取目标软件自带的语言文件，选一种已有语言为源，替换某种语言、补全目标语言缺的条目或新增目标语言；保护占位符；改前检查完整性校验 / 签名并拒绝不能改的；可一键还原，软件更新后自动重新生成 | P2 |
| F13 | 离线翻译（可选，非默认）：作为引擎列表中的一项，Windows 用 Bergamot（Firefox 同款）+ 按语言方向下载的模型，macOS 用系统 Translation 框架；可选"先显示离线译文、联网结果回来后替换"；沉浸模式可按应用只用离线翻译 | P2 |

## 明确不做

- 图像编辑、标注、贴图等截图软件功能。
- 历史记录/生词本（以后再说）。
- macOS / Linux 支持（第一版只做 Windows，发布 x64 与 ARM64 两个架构；其他平台的适配方案见 `02-技术方案.md`「多平台打包与发布」）。

## 验收标准（第一版）

- 在浏览器、PDF 阅读器、任意桌面应用上，快捷键 → 框选英文段落 → 2 秒内浮窗显示中文译文。
- 框选网页正文后滚动页面，译文跟随滚动，新出现的段落在 1 秒左右内被翻译。
- 拖动或缩放翻译框后，自动对新区域重新识别翻译。
- 翻译框存在时，下方软件的滚动、点击不受影响。
- 修改配置文件中的 base URL / key / 模型后重启生效（有设置界面则免重启）。
- OCR 失败、API 失败时浮窗内有可读的错误提示，不崩溃。
