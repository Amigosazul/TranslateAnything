### 0. 网络与 OCR 语言包（2026-11-16 补充）

- **代理**：环境变量 `HTTP(S)_PROXY=127.0.0.1:51828` 指向的不是 Clash，会让 HTTPS 握手失败（npm、rustup 均受影响）。本机 Clash Verge 的混合端口是 **7897**，经它访问 crates.io 约 9 MB/s（直连很慢）。执行 cargo / pnpm 前临时设置：

```bash
$env:HTTP_PROXY='http://127.0.0.1:7897'; $env:HTTPS_PROXY='http://127.0.0.1:7897'
```
- **Rust 镜像**：直连 static.rust-lang.org 只有约 40 KB/s，改用 rsproxy.cn（`RUSTUP_DIST_SERVER=https://rsproxy.cn`，`RUSTUP_UPDATE_ROOT=https://rsproxy.cn/rustup`）快约 10 倍。
- **英文 OCR**：设置 → 时间和语言 → 添加 English (United States)，勾选"光学字符识别"；或管理员 PowerShell：

```bash
Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"
```

验证可用语言（Windows PowerShell 5）：

```bash
powershell -NoProfile -Command "[void][Windows.Media.Ocr.OcrEngine,Windows.Foundation,ContentType=WindowsRuntime]; [Windows.Media.Ocr.OcrEngine]::AvailableRecognizerLanguages | % LanguageTag"
```

## 验证与补装步骤

### 1. 验证 VS Build Tools

```bash
ls "C:/Program Files (x86)/Microsoft Visual Studio/2022/BuildTools/VC/Tools/MSVC"
```

有版本号目录即已装好。没有则重装：

```bash
winget install --id Microsoft.VisualStudio.2022.BuildTools -e --override "--quiet --wait --norestart --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

### 2. 安装 Rust

```bash
curl -sSfL -o rustup-init.exe https://win.rustup.rs/x86_64
```

```bash
./rustup-init.exe -y --default-toolchain stable-x86_64-pc-windows-msvc
```

> 注：本机 Git Bash 的 curl 访问 win.rustup.rs 出现过 `schannel SSL/TLS` 握手失败，可改用 PowerShell `Invoke-WebRequest`、浏览器直接下载 https://rustup.rs ，或走代理。

装完重开终端，验证：

```bash
rustc --version && cargo --version
```

### 3. 创建 Tauri 项目骨架

在项目根目录下（骨架尚未创建时）：

```bash
pnpm create tauri-app@latest . --template vanilla-ts --manager pnpm --yes
```

然后按 `02-技术方案.md` 的目录结构调整，并加插件：

```bash
pnpm tauri add global-shortcut
```

### 4. 首次运行

```bash
pnpm install && pnpm tauri dev
```

首次 cargo 编译约 5–15 分钟，属正常。
